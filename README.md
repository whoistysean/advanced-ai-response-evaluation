About This Project

This project demonstrates practical skills in evaluating AI-generated responses across five key dimensions:

* Relevance
* Completeness

What This Project Demonstrates

Through practical exercises, I demonstrate my ability to:

* Identify factual errors and unsupported claims.
* Compare AI-generated responses.
* Evaluate whether instructions have been followed.
* Distinguish factual accuracy from presentation quality.
* Identify weaknesses and suggest corrections.
* Apply critical thinking and quality assurance.
